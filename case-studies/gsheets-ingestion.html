When the source of truth is a spreadsheet

Business teams keep their working data where they work: Google Sheets. Analytics needs it typed, versioned, and change-aware — without asking anyone to change tools, and without an engineer in the loop for every new sheet. Two ideas do all the work: a self-serve typed reader, and change capture built on snapshot diffing — because the Sheets API tells you what a sheet looks like now, never what changed.

The notebook

The pattern, step by step

Step 1 — read a sheet like an engineer

OAuth 2.0 with a cached refresh token: one interactive consent, then every scheduled run authenticates silently, scoped to spreadsheets only. The API hands back exactly what the user sees — strings, always, with trailing empty cells trimmed so row lengths vary. Typing is the pipeline’s job.

Step 2 — normalize the spreadsheet away

One function turns an API payload into an analytics-grade frame. Every line answers a real sheet pathology: ragged rows, header drift, human-formatted currency, checkbox strings, cleared-cell empties.

normalize: API payload → typed DataFrame 
def normalize(values):
    header, *rows = values
    width = len(header)
    rows = [r + [""] * (width - len(r)) for r in rows]      # pad ragged rows

    df = pd.DataFrame(rows, columns=header)
    df.columns = (df.columns.str.strip().str.lower()
                    .str.replace(r"\s+", "_", regex=True))   # header drift
    df = df.replace("", pd.NA)                               # cleared cells

    df["contact_date"] = pd.to_datetime(df["contact_date"], errors="coerce")
    df["monthly_volume_usd"] = (df["monthly_volume_usd"]
                                .str.replace(r"[$,]", "", regex=True)
                                .astype(float))              # $98,410.00 -> 98410.0
    df["follow_up_needed"] = df["follow_up_needed"].map({"TRUE": True, "FALSE": False})
    return df
contact_date datetime64[ns] monthly_volume_usd float64 follow_up_needed boolean

The dtype report is the point: a SUM(monthly_volume_usd) downstream now means something. And self-serve is a function signature — normalize(pull(url)) is everything an analyst needs for sheet number twelve.

Step 3 — capturing changes through the API

The Sheets API has no change feed. Three strategies, honestly compared:

StrategyHowVerdict
snapshot diffingpull the full range on a schedule, diff against the previous pullChosen. Sheets are small; the diff is exact (deletes included); the loader stays stateless beyond one stored snapshot.
Drive revisions APIfile-level revision historyTells you that the file changed, not which rows — a trigger signal, not CDC.
Apps Script onEditpush cell edits to a webhookTrue realtime, but code living inside each sheet — the opposite of self-serve.
capture_changes: row hash + set arithmetic 
def capture_changes(prev, curr, key="record_id"):
    p = prev.assign(_hash=row_hash(prev)).set_index(key)
    c = curr.assign(_hash=row_hash(curr)).set_index(key)

    inserted = c.index.difference(p.index)
    deleted  = p.index.difference(c.index)
    common   = c.index.intersection(p.index)
    updated  = common[c.loc[common, "_hash"] != p.loc[common, "_hash"]]

    return pd.concat([
        c.loc[inserted].assign(change_type="insert"),
        c.loc[updated].assign(change_type="update"),
        p.loc[deleted].assign(change_type="delete"),
    ]).drop(columns="_hash").reset_index()
change_type insert 3 update 2 delete 1

The bundled snapshots carry known ground truth — exactly 3 inserts, 2 updates, 1 delete — and the diff recovers all of it. Row-hashing beats column-watching: any cell change flips the hash, no schema knowledge required. And the delete is the part that matters — “just append the new pull” pipelines lose deletions forever.

Step 4 — land it, hand off to dbt

The loader stops at the raw layer: typed Parquet snapshot plus an append-only changelog, partitioned by pull date. Everything after that seam — staging models, tests that mirror the normalization rules, history — is dbt’s job now. The 2022 production original continued into hand-written Athena DDL and QuickSight wiring; that’s the part that aged out, and the notebook says so instead of pretending otherwise.
